    Use it

    1. Patch Discord Phoenix with Sunbird

      Install it from sunbird.tools on Discord Phoenix for Windows. Themes come with Sunbird's desktop-themes plugin: if it is not in Sunbird's settings yet, it arrives with the next Sunbird update.

    2. Download a theme

      Open a theme's page and press Download. You get a small .theme.css file.

    3. Apply it

      In Discord's settings, open Sunbird, then desktop-themes. Press Open themes folder, put the file there and reload the plugins, then pick your theme under Theme.
