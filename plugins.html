Plugins

A few plugins for Sunbird, read line by line before they are listed. Each one says what it can reach: the network, the Discord API with your session, your local message cache.

To install one, copy its link. Then in Discord's settings, open Phoenix (Sunbird on desktop), choose Install from URL (+ URL on desktop) and paste it.
