    Use a theme

    1. Patch Discord Phoenix with Sunbird

      Get Discord Phoenix for Windows and Sunbird from sunbird.tools. Desktop themes need Sunbird 0.1.1 or newer, and its launcher updates itself every time it starts.

    2. Add Ultracord Themes

      In Discord's settings, open Sunbird, choose + URL and paste this link. The plugin only reaches assets.ultracord.dev.

      https://assets.ultracord.dev/plugins/ultracord-themes.js

    3. Pick a theme

      In the plugin's settings, choose a theme under Theme. It applies at once, comes back when Discord starts and updates itself when the theme does.

    Rather use Sunbird's own desktop-themes plugin? Install it from Sunbird's plugin catalog (under Unverified for now), download a theme from its page, put the file in its themes folder with Open themes folder, reload the plugins and pick the theme under Theme.

    Contribute

    Themes are .theme.css palettes and plugins are TypeScript files, both submitted as pull requests on GitHub. A theme has to keep its text readable on its backgrounds. A plugin is refused if it:

    • loads or runs code it does not ship with;
    • sends your data anywhere its description does not mention;
    • acts on your account without you asking;
    • is obfuscated or minified.
