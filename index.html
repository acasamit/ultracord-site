More plugins for Sunbird

Ultracord is a community store of plugins and themes for Sunbird, the Discord Phoenix unlocker. Every plugin is read line by line before it ships.

Each plugin lists what it can reach before you install it: the network, the Discord API with your session, your local message cache. Nothing is hidden in a minified file.

    Themes

    Phoenix draws Discord natively, without CSS, so themes need support from Sunbird itself. That work is in progress upstream. Theme submissions open as soon as it lands, and existing mobile themes should carry over.

    Install

    1. Patch Discord with Sunbird

      Open sunbird.tools on your phone and keep the plugin runtime turned on. Desktop Phoenix works too.

    2. Add Ultracord

      In Discord, go to Settings, Phoenix, Install from URL, and paste this link:

      https://assets.ultracord.dev/plugins/ultracord.js

    3. Pick your plugins

      Open Ultracord from the button in the chat header. It shows every plugin, what it can access, and tells you when an update is out.

    Contribute

    Plugins are TypeScript files submitted as pull requests on GitHub. A submission is refused if it:

    • loads or runs code it does not ship with;
    • sends your data anywhere its description does not mention;
    • acts on your account without you asking;
    • is obfuscated or minified.
